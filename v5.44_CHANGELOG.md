# Zone-Engine v5.44 — Signal Forensics Telemetry

No strategy gates, entry rules, TP/SL levels, score thresholds, volume thresholds, direction rules, zone age limits, or BE trigger values were changed.

Added only deterministic telemetry:
- signal-candle wick/body/close-location measurements;
- zone width and penetration measurements;
- zone POI / edge distance in ATR;
- signal forensics persisted into active trade research and close records;
- MFE milestone timestamps for 0.25R / 0.50R / 1R / 2R observations;
- BE trigger/activation timestamps and peak R;
- BE order id, trigger price, actual fill price and measured adverse execution slippage when exchange data is available;
- exit STOP order trigger/fill/slippage telemetry.

The measurements are diagnostic only and never reject a signal.
